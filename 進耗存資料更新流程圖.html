執行前確認

來源必要準備
202610.xlsx完整十月份實發量與庫存量。工作表名稱須能轉換為 11510；例如 2026年10月。
2026_out.xlsx確認十月份資料及必要欄位，轉為 Data/OUT/11510.csv。
2026_ud.xlsx確認十月份資料及必要欄位，轉為 Data/UD/11510.csv，須包含 phtxid。
base.xlsxbase 工作表含 drug_id、drug_name、drug_type。若有新藥，先以完整新版更新資料庫主檔。

篩選程式會讀取指定資料夾內所有 CSV；請確認其中每個檔案與月份均為本次預期處理的資料。

指令順序

uv run rename_monthly_xlsx.py "202610.xlsx"
uv run out_screen.py
uv run ud_screen.py
uv run total_screen.py
uv run update_summary.py --dry-run
uv run update_summary.py
uv run scripts/build_inventory.py --output sites/inven-viz/dist/index.html

若需要更新藥品主檔，先執行 uv run update_summary.py --replace-base --dry-run，確認後執行 uv run update_summary.py --replace-base。預演須先檢查輸入筆數、排除筆數、缺耗量補零及替換月份。

發布與驗證

檢查 11510 年月、抽查品項數量及下載內容後，使用 Sites 工作流程同步既有網站的專用來源、封裝、保存版本並部署；確認部署成功與公開頁面。資料庫或一般 GitHub 更新不會自行完成 Sites 部署。

來源依專案 README 與 Sites 正式發布紀錄。此頁為流程示範，並未執行資料更新或部署。
