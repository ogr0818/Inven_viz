## 分析目的及資料層次

觀察指定連續年月區間內，各藥品品項的「實發量」「total_qty」「庫存量」。以 drug_id 區分品項，不跨品項加總，drug_name 用於呈現而非整併鍵。

| 資料層 | 每列粒度 | 用途 |
| --- | --- | --- |
| 本地 summary.xlsx | drug_id + inv_year + inv_month | 保存年度分表的每月明細，供網站更新 |
| 網站統計結果 | 每個 drug_id 在套用區間的彙總 | 圖表及畫面統計表 |
| 下載 Excel | drug_id + inv_year + inv_month | 符合篩選條件的逐月明細，供後續加工 |

網站先篩選年月區間及可納入的品項月份，再分品項彙總及排序。Excel 明細下載直接取篩選後月明細，不使用已彙總的畫面資料。

## 資料來源與整備

- 月報作為品項基準；對話中的「月報.xlsx」目前對應本地的「月報表.xlsx」。其他來源多出的品項忽略。
- 基本資料依 drug_id 併入 drug_name、drug_type；耗量依 drug_id、inv_year、inv_month 併入。
- 每個品項每月一筆資料，唯一鍵為 drug_id + inv_year + inv_month。
- 2026-10-10 整併決策：月報品項月份的「實發量」必須大於 0；小於或等於 0 的整筆排除，取代先前保留零值的約定。
- 月報有品項，但耗量表沒有同年月紀錄時，total_qty 填 0。
- total_qty 保留原始正負號。
- 同一 drug_id 的三種數量視為相同單位。
- 保留「實發量」「total_qty」「庫存量」原欄名，不另作業務定義。
- 耗量缺紀錄補零後，無法再由 total_qty 區分來源明確為零與無對應紀錄；這是已選定處理規則的限制。下載定位為整併並篩選後的月明細，不宣稱完全未處理的原始來源。

## 本地彙整檔案

- 每月整理完成後，資料保存在本地 summary.xlsx。
- 每個年份一張工作表，名稱為民國年份，例如 115、116。
- 各年度工作表保留每月明細；inv_year 與工作表年份一致。
- 暫訂欄位順序：drug_id、drug_name、實發量、total_qty、庫存量、inv_year、inv_month、drug_type。

## 網站資料更新

- 手動執行網站資料更新，不因本地存檔而自動同步。
- 每次更新以整份 summary.xlsx 替換網站資料，不追加或合併舊版本。
- 全檔通過檢查後才替換。缺必要欄位、年份不一致、重複唯一鍵等檢查失敗時，取消此次更新並列出錯誤位置，網站保留原資料。
- 發布目標為 Sites，具體更新操作介面及實作方式於後續實作階段安排。

## 年月區間與統計

- 起始與結束各一組年份、月份下拉選單，選取連續區間，包含起訖月份，可跨年。
- 年份只列出有月報資料的年份；月份固定呈現 1–12 月。
- 起始年月不得晚於結束年月。
- 首次開啟自動使用月報最新月份並呈現結果。
- 後續修改起訖年月後，按「套用區間」才更新圖表、表格、候選品項與資料年月提示。
- 顯示選取區間及實際資料年月；若區間有缺月，列出缺少的年月，不以一個連續標籤掩蓋中間缺月。
- 本地整理時以月報為基準檢查原始來源缺月並提示；網站只檢查 summary.xlsx，年份選項與實際資料年月依其中的月報基準資料建立。網站不從已補零的數值推測原始耗量來源是否整月缺失。
- 各品項分開統計，不將不同品項加總。
- 實發量、total_qty 分別按所選區間中可納入的品項月份資料加總。
- 庫存量優先取套用區間結束月份的該品項可納入資料；若缺少，僅向前尋找區間內最近一筆可納入資料，不採區間外或結束月份之後的庫存。區間內均無可納入庫存資料時顯示「無資料」，不填 0。保留實際採用的庫存所屬年月。單月查詢僅採該月。

## 圖表、表格及排序

- 依 IMG_7443.HEIC 草圖改為三欄並排的橫向長條圖：實發量、total_qty、庫存量。左側共用 drug_name，各品項在三欄中保持同一列，不採先前同一繪圖區域內每品項三根長條的排列。
- 三欄上方直接呈現各自欄位名稱，保留整體圖表標題，不以圖例辨識三個欄位。
- 圖表不設外框或欄位邊框，配置儘量靠左，各欄以零線為長條基準；負值向零線左側延伸。長條右側保留數值標籤，底部不顯示數值範圍文字。
- 每個品項的「庫存量」長條上標註實際採用的民國年月，例如 11509；採用結束月份或較早月份均標註。數值為 0 或長條太短而容不下年月時，年月改在長條右側外標記。庫存數值仍保留在長條右側，年月與數值須避免重疊。此標註亦保留於下載 PNG。
- 同一欄位內所有品項的零點固定在同一條垂直線上，不依各長條長度各自置中。圖表版型_prototype.html 的示意版型已由使用者確認，僅作外觀參考，尚未接入正式資料。
- 各欄 X 軸表示各自數量，三欄使用相同數值尺度，水平移動及縮放同步。垂直移動保持三欄品項對齊；數值範圍須涵蓋 total_qty 的負值。
- 上方使用「圖表／表格」切換檢視，預設圖表，一次顯示一種檢視。
- 兩種檢視呈現完整符合條件的結果，採整頁捲動，不分頁、不限前 N 項。
- 預設依期間實發量合計由大到小排序。
- 點選表格欄名可切換排序，切回圖表時採相同排序。
- 切換檢視保留套用區間、品項選擇及排序。
- 畫面統計表新增「庫存年月」單一欄位，顯示各品項實際採用的民國年月，例如 11509；套用的查詢區間統一顯示於表格上方，不將期間累計的年月與庫存年月混用。此欄位不改變下載月明細的 inv_year、inv_month 兩欄。
- 點選圖表或表格不改變品項選擇；品項只透過搜尋與下拉選單選取。

## 單一品項搜尋

- drug_id 固定 6 碼，英文字母使用大寫；以完整代碼配對。
- 下拉候選項目顯示 drug_id、drug_name，依 drug_name 升冪排序。
- 候選範圍限於套用區間中有可納入資料的月報品項。
- 格式不符或無配對須提示。無配對不改變目前結果。
- 選取後，圖表及表格只呈現該品項；清除選取後恢復全部符合條件品項。
- 套用新區間後若原選品項無可納入資料，保留選取並提示無符合資料，不自動切回全部品項。

## 下載

- 圖表與表格各自分頁內容下方設下載按鈕，由使用者觸發。
- 圖表為 PNG；表格為 Excel（.xlsx）。
- PNG 下載目前套用區間與品項篩選後的完整圖表，保留目前品項排序。
- PNG 標題下方僅標註套用的查詢區間，例如「查詢區間：11501–11509」，不另列實際資料年月或缺月清單。各品項的庫存年月標註照常保留。網頁上的實際資料年月及缺月提示仍依已確認規則呈現。
- Excel 下載供進一步加工的逐月明細，並非畫面上的期間彙總。依目前套用區間與品項選擇篩選，僅納入實發量大於 0 的品項月份資料；這是符合分析條件的整併後月明細，不是完全未處理的原始來源。
- Excel 明細保留八欄及順序：drug_id、drug_name、實發量、total_qty、庫存量、inv_year、inv_month、drug_type。每列代表一個品項月份，inv_year、inv_month 為該筆月明細的年月；不跨月加總，也不以最後一期庫存替換各月庫存。total_qty 保留原正負號，來源無對應紀錄填 0 的規則沿用。
- Excel 僅有一張「月明細」工作表，第一列即為八個欄名，不另附篩選資訊工作表，不在明細上方插入說明列；依 inv_year、inv_month、drug_id 升冪排序，與畫面品項排序分開。
- 支援的瀏覽器以桌面作為建議起始位置，使用者可變更儲存位置及檔名。桌面起始位置及儲存對話框受瀏覽器能力影響，不作跨瀏覽器保證。
- 成功儲存後顯示實際檔名；取得資料夾名稱時可一併顯示，不顯示完整絕對路徑。
- 一般瀏覽器下載流程若無法確認實際寫入完成，僅能提示已開始下載，不能宣稱已儲存成功。
- 建議檔名為「類型_起始年月-結束年月_品項.副檔名」；類型為「圖表」或「表格」，全部品項使用「全」，單一品項使用 drug_id。
- 單月檔名簡化為單一年月，例如「圖表_11509_ACT03I.png」；跨年保留起訖年月，例如「表格_11511-11602_全.xlsx」。檔名採套用區間，使用者儲存時可修改檔名。Excel 的實際年月由明細的 inv_year、inv_month 保留，不另加說明列或篩選資訊工作表。
