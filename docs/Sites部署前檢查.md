## 首次發布前規劃（歷史流程）

以下為當時首次註冊新網站的規劃，不適用於既有網站的日常更新。當時預計使用 Sites 技能的靜態網站流程，另準備專用 Site 來源子目錄，公開資產只放 `dist/index.html`，不把本資料整理專案整份當成 Site 來源上傳。註冊後立即保存回傳的 Site ID，設定靜態目錄為 `dist`，完成來源同步與封裝，再保存版本並部署。公開免登入目標須將該 Site 訪客權限設為 `public`；新 Site 預設私人，不能只依部署成功就宣稱已公開。

發布成功後核對正式網址、部署終態與公開存取設定。當時規劃資料更新需更新本機 DB、重新產生 `dist/index.html` 並發布新版，不會自動同步。現行流程另須統一三份 HTML，請依 README 執行。
